- The techniques, algorithms, and designs implemented in this project are
  **publicly disclosed as prior art** as of their first git commit date
  (see [`PRIOR_ART.md`](PRIOR_ART.md)).
- Contributors **cannot** patent anything derived from this project's code
  or documented techniques.
- Their employers **cannot** either — the Contributor License Agreement
  ([`CLA.md`](CLA.md)) explicitly requires contributors to warrant that
  their employer holds no IP claims over their contribution, and to
  indemnify the project if that turns out to be false.
- If anyone — contributor, employer, or third party — asserts a patent
  against this project or its users, **all their licenses terminate
  immediately** and the project will defend itself using the prior art
  documented here.
- The project currently holds **no offensive patents**. If patents are ever
  obtained, they will be used **only defensively** — to counter-sue anyone
  who sues this project or its users.

> **Neither the Maintainer nor the Project will assert any patent that
> covers inventions implemented in this software against any person or
> entity for their use, study, modification, or distribution of this
> software or software substantially interoperable with it, except in
> defensive response to a patent assertion initiated by that person or
> entity against this Project or its users.**

This pledge is binding on the Maintainer and on any successor or assign
of the Project. If the Project is transferred or acquired, the acquiring
party must agree in writing to honor this pledge as a condition of the
transfer.

This pledge does **not** extend to unrelated patent claims (patents that
cover inventions not present in this project) asserted by a third-party
aggressor.

## 4. Defensive Publication

All novel techniques in this project are **publicly disclosed** in
[`PRIOR_ART.md`](PRIOR_ART.md) with their first-publication dates
(the date of the git commit that introduced them, on a public repository).

Under US patent law (35 U.S.C. §102) and most jurisdictions, prior art
that predates a patent application by at least one year bars that
application from being granted. Because this project is public on GitHub,
every technique described in `PRIOR_ART.md` is prior art as of its
commit date.

If you discover that a third party has filed a patent application on a
technique documented here, please open a GitHub Issue with details so
the Maintainer can take appropriate action (submit prior-art evidence to
the USPTO or relevant patent office, challenge the application, etc.).
