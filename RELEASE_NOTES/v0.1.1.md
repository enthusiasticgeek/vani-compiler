# vāṇी v0.1.1 — 2026-06-18

Patch release with four new concurrency primitives, extended generics, and package manager improvements.

---

## Language

### `Barrier` — N-thread rendezvous

```
let b: Barrier = barrier_new(4);
let is_last: bool = barrier_wait(mut ref b);
```

Stack-allocated, affine. Uses a generation counter to prevent ABA races: the last thread increments `gen` and wakes all waiters; others spin/sleep until `gen` changes. Returns `true` for the last thread to arrive.

Both C and LLVM backends fully supported. LLVM: inline IR with `phi i1` at the join point; C: `_Atomic int64_t count`, `_Atomic int gen` with futex/WaitOnAddress wakeup.

---

### `RwLock<T>` / `ReadGuard<T>` / `WriteGuard<T>` — readers-writer lock

```
let rw: RwLock<i64> = rwlock_new(0);
let r: ReadGuard<i64>  = rwlock_read(ref rw);
let v: i64             = read_guard_get(ref r);

let w: WriteGuard<i64> = rwlock_write(mut ref rw);
let _: i64             = write_guard_set(mut ref w, v + 1);
```

State encoding: `0` = unlocked, `N > 0` = N concurrent readers, `-1` = write-locked.

- `rwlock_read` — acquires a shared read guard; spins if write-locked.
- `rwlock_write` — acquires an exclusive write guard via CAS 0→−1; parks on failure.
- Guards are RAII: `Drop` on `ReadGuard` / `WriteGuard` calls `_unlock`, which decrements the reader count or resets `−1 → 0`.
- Parametric over any element type `T`; per-T C struct bundles are generated at compile time via `collect_rwlock_specs`.

---

### Parametric `Mutex<T>` / `Guard<T>`

Previously `Mutex` was i64-only. Any element type is now accepted: integers, `bool`, structs, enums. Per-T C struct bundles are synthesized by `collect_mutex_specs`/`emit_mutex_bundle`. The LLVM backend emits matching per-T LLVM types.

---

### Parametric `Channel<T, N>`

`Channel` now accepts struct and enum element types in addition to integer widths and `bool`. C backend uses `c_element_storage` with `memset` zero-initialisation for aggregate slots. LLVM backend uses `channel_slot_llvm_string` for aggregate slot types.

---

### Traits — phase 2

- **Default methods** in interface declarations: `interface Foo { fn bar(self: ref Self) -> i64 { 0 } }`.
- **Blanket implementations**: `implement<T> Iface for Wrapper<T> where T is Iface { … }`.
- Satisfiability checking with bounded generics: the compiler verifies that every method required by `Iface` is present on `T` before accepting the blanket impl.

---

## Package manager (kosh)

- **Runtime download URL** — configurable via `config.json` (`"registry"` field). Useful for private mirrors.
- **Custom CA certificate** — `"cafile"` field in `config.json` points to a PEM file for private registries with self-signed TLS.

## Installation

```sh
# Linux / macOS
curl -fsSL https://raw.githubusercontent.com/enthusiasticgeek/vani-compiler/main/install.sh | sh

# Windows (PowerShell)
irm https://raw.githubusercontent.com/enthusiasticgeek/vani-compiler/main/install.ps1 | iex
```

Pre-built binaries for Linux x86_64/aarch64, macOS x86_64/aarch64, and Windows x86_64 are attached to this release.
