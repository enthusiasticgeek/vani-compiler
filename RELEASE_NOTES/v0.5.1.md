# vāṇी v0.5.1 — 2026-07-17

Feature release. Closes out the L-series and XL-series work queued after v0.5.0.

## What's new

- **Closure capture of affine (non-Copy) bindings** (L5) — a closure can now capture a `Vec`/`OwnedStr`/other affine value by reference, not just Copy scalars.
- **`select { await poll then binding { body } }` syntax** (L3) — first-class async multiplexing over several pending futures.
- **Runtime integer overflow guards for `Add`/`Sub`/`Mul`** (L4), with SMT elision when the compiler can prove overflow is impossible.
- **Slice/vec destructure patterns in `match`** (L1) — `[first, .., last]` on `Vec<T>` and `[T; N]`.
- **`#[repr(C)]` / `#[repr(packed)]` struct layout attributes** (L2).
- **`Vec<bool>` packed bit-array representation** (XL1) — 8x memory reduction vs `Vec<i64>`-as-bool.
- **`vanic test` built-in test runner** (XL2).
- **`for await x in expr` stream syntax** (XL3), desugars to a `while let` poll loop.
- **Multi-pass monomorphizer** (XL4) — fixes nested generic function chains that a single monomorphization pass couldn't fully resolve.

## Bug fixes

- Fixed a curly-quote encoding bug in `parser.rs` found while building the `vanic test` runner.
- CI: removed a shadowing XL2 test arm that had silently broken the `test` subcommand's own test coverage.

## Upgrade notes

- No breaking changes.
