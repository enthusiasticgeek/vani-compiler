# vāṇी v0.8.0 — 2026-07-22

`pub(kosh)` is now actually enforced — a follow-up to v0.7.0's Kosh
package namespacing arc, closing the gap documented as L23 in the known
limitations catalog.

---

## `pub(kosh)` now blocks external Kosh-package access

`pub(kosh)` was accepted syntax since an earlier release but never
actually restricted anything — it behaved identically to plain `pub`
at every call site. As of this release, a `pub(kosh)` item is
genuinely rejected when a *different* Kosh package (a `[deps]`
consumer) reaches for it:

```vani
// vendor/mypkg/src/lib.vani
pub(kosh) fn internal_helper(x: i64) -> i64 { return x * 2; }
pub fn public_api(x: i64) -> i64 { return internal_helper(x) + 1; }
```

```vani
// consumer project, [deps] mypkg = { path = "./vendor/mypkg" }
let a: i64 = mypkg::public_api(5);        // OK — 11
let b: i64 = mypkg::internal_helper(5);   // error: pub(kosh) — visible
                                           // only within its own package
```

Use `pub(kosh)` to mark a Kosh package's internal helpers as off-limits
to whoever depends on it, while keeping them usable from elsewhere in
the package's own source.

### Known remaining gap

A same-project sibling module (not an external Kosh consumer) reaching
into a *different* module's `pub(kosh)` item is currently **also**
rejected — stricter than the intended "visible within your whole
project" design. This isn't a regression (previously nothing was
enforced at all), but it means `pub(kosh)` isn't yet a full substitute
for `pub` when sharing a helper across your own project's modules. Use
plain `pub` for that until real caller-identity tracking lands. Full
detail: [L23](https://github.com/enthusiasticgeek/vani-compiler/blob/main/docs/v1_limitations.md).

---

## Upgrade notes

- No syntax, IR, or ABI breaking changes.
- If you were relying on `pub(kosh)`'s previous no-op behavior to call
  a Kosh dependency's `pub(kosh)` item unqualified-externally, that
  call site will now fail to compile — this was never the intended
  behavior, and no published kosh package used `pub(kosh)` at all, so
  this shouldn't affect any real project.
