# v0.1.8 — Block Comments, Print Blocks, Positional Break (2026-06-23)

## New language features

### Block comments `/* ... */`

Multi-line block comments are now supported. They may be nested to any depth:

```vani
/* outer /* nested */ still outer */
let x: i64 = /* inline */ 42;
/**/  /* empty comment */
```

Unterminated block comments produce a clean diagnostic (no panic).

### Print block `print { ... }`

Group multiple print lines under a single `print` keyword. Each `;`-terminated
group becomes a separate output line — no more repeating `print` on every line:

```vani
print {
  "name: ", name;
  "score: ", score;
  "rank: ", rank;
}
```

Equivalent to three separate `print` statements. Works inside loops and
alongside regular `print` / `eprint`. Both C and LLVM backends supported.

### Positional break: `break inner`, `break middle`, `break outer`

Exit a specific enclosing loop by position — no need to label loops manually:

```vani
while outer_cond {
  while middle_cond {
    while inner_cond {
      if done { break outer; }   /* exit all three loops */
      if skip { break middle; }  /* exit middle + inner */
      if next { break inner; }   /* exit innermost only */
    }
  }
}
```

| Keyword | Target |
|---------|--------|
| `break inner` | Innermost enclosing loop (same as plain `break`) |
| `break middle` | Second-from-innermost loop |
| `break outer` | Outermost enclosing loop |

`break outer` / `break middle` in a single-loop context behave like `break`.
`break middle` in a two-loop context behaves like `break outer`.
Both the SSA-C and LLVM backends generate correct labeled exits.

## Adversarial tests added

Eight new edge-case programs covering:
- Deeply-nested `/* /* /* */ */ */` block comments and empty `/**/`
- `xfail`: unterminated block comment rejected cleanly
- `print { }` inside a `for` loop
- `break outer` in a single-loop context
- `break middle` in a two-loop context  
- `break inner` in a three-deep nest verifying only the innermost exits

All pass on both the C and LLVM backends.
