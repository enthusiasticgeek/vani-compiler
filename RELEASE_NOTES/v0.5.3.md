# vāṇी v0.5.3 — 2026-07-17

Feature + performance release. Closes out the G-series work queued after v0.5.2.

## What's new

- **Generic trait bounds inline syntax** (G1) — `fn f<T: Iface>(x: T)` as sugar for `where T is Iface`.
- **`clone_at` on `Vec<(i64, OwnedStr)>`** (G2) — Tuple + `OwnedStr` element support.
- **`Atomic<T>` extended to `f64`** (G3), alongside the existing integer element types.

## Performance

- Replaced Lomuto introsort with pdqsort (branchless block partitioning) in the standard sort.
- Added ascending/reverse-sorted pattern-detection passes ahead of the main sort.
- AVX-512 bitmask scan + forward right-scan (`__builtin_clzll`) for the sort's partition step.
- Replaced per-invocation thread spawn with a persistent pthread pool for `parallel for`.
- Added `getelementptr inbounds` to every `Vec`/`Array` GEP in the LLVM backend.

## Bug fixes

- Fixed the LSP test helper's `Uri` construction to use `FromStr` (fluent-uri API compatibility).

## Upgrade notes

- No breaking changes.
