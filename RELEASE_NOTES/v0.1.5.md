# vāṇī v0.1.5 — 2026-06-21

Native file I/O — `FileHandle`, stdin, stderr, and a full RAII file API
across both the C and LLVM backends.

---

## Native file I/O — `FileHandle` and friends

vāṇī now ships a typed, affine file-handle type and a small suite of
standard-library builtins that cover the common read/write/close loop.
`FileHandle` is **affine** (moved on use, auto-`fclose`d at scope exit)
so file descriptors never leak — even on early returns.

### New builtins

| Builtin | Signature | Notes |
|---|---|---|
| `file_open` | `(path: Str, mode: Str) -> FileHandle` | Opens a file; handle is ok if `file_is_ok` returns true |
| `file_is_ok` | `(fh: ref FileHandle) -> bool` | Returns false if `fopen` returned NULL |
| `file_read_line` | `(fh: mut ref FileHandle) -> OwnedStr` | Reads one line (newline included); returns `""` at EOF |
| `file_write` | `(fh: mut ref FileHandle, s: Str) -> i64` | Writes a string; returns bytes written or -1 on error |
| `file_close` | `(fh: FileHandle) -> i64` | Closes and consumes the handle (also fires automatically at scope exit) |
| `file_flush` | `(fh: mut ref FileHandle) -> i64` | Flushes the internal buffer |
| `stdin_read_line` | `() -> OwnedStr` | Reads one line from stdin |
| `flush_stdout` | `() -> i64` | Flushes stdout |

### `eprint` statement

`eprint` works like `print` but writes to **stderr**:

```vani
eprint "error: something went wrong";
eprint code;
```

Multiple items are space-separated on the same line. Both the C and LLVM
backends route `eprint` through `fprintf(stderr, ...)`.

### L18 resolved

`docs/v1_limitations.md` item L18 ("native file I/O") is now marked
**shipped** in this release.

### Example

```vani
// examples/language/english/file_io.vani
fn main() -> i64 {
    let fh: FileHandle = file_open("data.txt", "w");
    if file_is_ok(ref fh) {
        let _ = file_write(mut ref fh, "hello from vāṇī\n");
        let _ = file_flush(mut ref fh);
    } else {
        eprint "could not open data.txt";
    }
    let _ = file_close(fh);  // also auto-called at scope exit

    let rfh: FileHandle = file_open("data.txt", "r");
    if file_is_ok(ref rfh) {
        let line: OwnedStr = file_read_line(mut ref rfh);
        print line;
    }
    let _ = file_close(rfh);
    return 0;
}
```

## Installation

```sh
# via crates.io
cargo install vani

# Linux / macOS
curl -fsSL https://raw.githubusercontent.com/enthusiasticgeek/vani-compiler/main/install.sh | sh

# Windows (PowerShell)
irm https://raw.githubusercontent.com/enthusiasticgeek/vani-compiler/main/install.ps1 | iex
```

Pre-built binaries for Linux x86_64/aarch64, macOS x86_64/aarch64, and
Windows x86_64 are attached to this release.
