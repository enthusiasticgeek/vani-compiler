# vāṇी v0.1.2 — 2026-06-19

Patch release with ABI improvements, finer dialect purity, expanded tutorials, and the first crates.io publication.

---

## Platform ABI — Win64 & AArch64

`extern fn` struct-return and struct-parameter checking now dispatches to the correct ABI at compile time:

| Platform | Rule |
|----------|------|
| SysV x86-64 (Linux, macOS) | All-scalar fields; total ≤ 16 bytes |
| Win64 (Windows x86-64) | All-scalar fields; size ∈ {1, 2, 4, 8} bytes |
| AArch64 (ARM64) | HFA (1–4 identical f32/f64 fields) OR all-scalar ≤ 16 bytes |

Platform-specific error hints are included in rejection diagnostics.

---

## Dialect Purity — Sanskrit / Hindi / Marathi

The `// vani-lang:` pragma already enforced sub-dialect purity via `spelling_supports_dialect`; all 45 Devanagari structure-keyword aliases are verified in the dialect table. Documentation updated to reflect the implementation status.

---

## Language / Lexer

- `intentc` binary now prints a deprecation warning at startup — migrate to `vanic`.
- All four previously English-only keywords (`extern` / `type` / `intent` / `invariant`) have Devanagari aliases wired and tested: `बाह्य` / `प्रकार` / `उद्देश्य` / `अपरिवर्तनीय`.

## Installation

```sh
# via crates.io (new in this release)
cargo install vani

# Linux / macOS
curl -fsSL https://raw.githubusercontent.com/enthusiasticgeek/vani-compiler/main/install.sh | sh

# Windows (PowerShell)
irm https://raw.githubusercontent.com/enthusiasticgeek/vani-compiler/main/install.ps1 | iex
```

Pre-built binaries for Linux x86_64/aarch64, macOS x86_64/aarch64, and Windows x86_64 are attached to this release.
