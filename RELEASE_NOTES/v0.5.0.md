# vāṇī v0.5.0 — 2026-07-15

Six new features and fixes across the match system, SIMD, and generics.

---

## New language features

### `if let` / `while let` pattern binding (M1)

Bind a variable from an `Option` or enum payload directly in a
conditional or loop without a full `match`:

```vani
if let Opt.Some(n) = find(xs, target) {
    print n;
}

while let Opt.Some(item) = deque_pop_front(ref mut q) {
    process(item);
}
```

Both forms lower to a match internally; the bound variable is only in
scope inside the `then` body (and each iteration for `while let`).

### Or-patterns in match arms (M2)

Combine multiple patterns in a single arm with `|`:

```vani
match status {
    Status.Ok | Status.Pending then handle_active(),
    Status.Error               then handle_error(),
}
```

The compiler expands each `|`-joined pattern into a separate arm
before type-checking, so each arm body is checked once against
the union of patterns.

### Pattern guards in match arms (M3)

Add an `if <expr>` guard after a pattern to refine which values
an arm matches:

```vani
match opt {
    Opt.Some(n) if n > 0 then { print "positive"; n },
    Opt.Some(n)          then { print "non-positive"; n },
    Opt.None             then 0,
}
```

Guards are evaluated after the variant test. An unguarded arm for
the same variant acts as the fallback; the two arms are merged into
a single switch case with an `if`/`else` inside to avoid duplicate
case labels.

### `vec512<T>` + `simd512_*` builtins (M4)

512-bit SIMD register type targeting AVX-512, SVE-512, and RISC-V
RVVE with VLEN=512. Mirrors `vec256<T>` exactly:

```vani
let a: vec512<f32> = simd512_splat(1.0 as f32);
let b: vec512<f32> = simd512_splat(2.0 as f32);
let c: vec512<f32> = simd512_add(a, b);
let s: f32         = simd512_reduce_add(c); // 16 lanes * 3.0 = 48
```

7 builtins: `simd512_splat`, `simd512_load`, `simd512_store`,
`simd512_add`, `simd512_sub`, `simd512_mul`, `simd512_reduce_add`.
LLVM backend emits `<N x T>` vectors with 64-byte alignment; C backend
uses `__attribute__((vector_size(64)))`.

## Bug fixes

### OwnedStr payload double-free in by-value enum match (M5)

`fn identity(m: Msg) -> OwnedStr { match m { Msg.Text(s) then s, … } }`
previously crashed with exit code 116 (double-free). The scrutinee's
scope-exit Drop freed the payload buffer that had just been returned as
the function result.

Fix: when the arm body is exactly the binding variable (direct move-out),
the binding is now typed as `OwnedStr` (char\*) and the scrutinee
variable is marked as moved — preventing the scope-exit Drop from firing.
All other binding uses (view-only via `len(s)`, etc.) continue to use the
`Str` (const char\*) view and rely on the scrutinee Drop as before.

### Generic T inference through user-defined Apply constructors (M6)

`fn unbox<T>(w: Wrap<T>) -> T` called with a `Wrap<i64>` argument
previously inferred `T = Struct("Wrap__i64")` (the entire monomorphized
type) instead of `T = i64`, generating garbage specialization names like
`unbox__Struct_Wrap__i64__`.

Fix: `unify_param_to_arg` now handles `Apply { name, args: [Param(T)] }`
vs `Struct("name__suffix")` / `Enum("name__suffix")` by stripping the
constructor prefix and un-mangling the scalar suffix to recover `T`.
Also adds an `Apply`/`Apply` arm for cases where type-decl mono has not
yet collapsed the concrete side.

## Upgrade notes

- No syntax, IR, or ABI breaking changes. Existing programs recompile
  without modification.
- `vec512<T>` requires an AVX-512-capable CPU (or emulator) to run the
  generated code; the compiler itself builds and runs on any x86-64 or
  AArch64 host.
