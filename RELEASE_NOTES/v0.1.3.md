## System requirements — now documented

`INSTALL.md` gains a full **System Requirements** section so users know
exactly what's needed before they start:

### Minimum tool versions

| Tool | Minimum version |
|---|---|
| Rust | 1.75 (2023-11-16) |
| z3 | 4.8.x |
| LLVM (`lli` / `llc` / `opt`) | 14 (tested through 22) |
| C compiler (gcc / clang) | 9 |
| Python | 3.8+ (optional — translator + MCP only) |

## Older Linux guide (Debian 10 Buster)

Debian 10's apt repo ships z3 4.4.1 (too old). A new subsection in
`INSTALL.md` gives the step-by-step manual install using the z3 4.8.17
ubuntu-18.04 pre-built binary — its glibc 2.27 requirement is satisfied
by Buster's glibc 2.28. Includes a `--backend=c` fallback note to
avoid Buster's older LLVM 7.

## Installation

```sh
# via crates.io
cargo install vani

# Linux / macOS
curl -fsSL https://raw.githubusercontent.com/enthusiasticgeek/vani-compiler/main/install.sh | sh

# Windows (PowerShell)
irm https://raw.githubusercontent.com/enthusiasticgeek/vani-compiler/main/install.ps1 | iex
```

Pre-built binaries for Linux x86_64/aarch64, macOS x86_64/aarch64, and
Windows x86_64 are attached to this release.
