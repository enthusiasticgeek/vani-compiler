# vāṇī v0.9.7 — 2026-09-16

## What's new

- **`[expr; N]` array-repeat literal syntax** — build a fixed-size array by
  repeating one expression N times, matching the ergonomics gap found
  while extracting DhruvaOS's crypto packages.
- **Uninitialized `let x: T;`** now allowed for zero-default-able types,
  instead of requiring an explicit initializer everywhere.
- **`mut ref T -> ref T` reborrow** now allowed at call-argument position
  (previously only worked in a few other contexts).
- **`[T; N]` is now `Copy`** whenever its element type `T` is `Copy`,
  closing an ergonomics gap where fixed-size arrays of trivially-copyable
  elements had to be manually cloned.
- **DHDL v0.1 MVP**: new `#[mmio(size=N)]` attribute plus a whole-program
  memory-mapped-I/O overlap check, documented in the language manual —
  the first piece of hardware-description support aimed at bare-metal
  kernel work (DhruvaOS).

## Bug fixes

- **BUG-228**: `--no-std` C emission no longer pulls in `pthread.h`/`signal.h`.
- **BUG-229**: `strlen` is no longer declared `i64`, fixing garbage results
  on 32-bit targets.
- **BUG-230**: diagnostic rendering no longer panics when a `Span` lands
  mid-character (multi-byte UTF-8 boundary).
- **BUG-231**: `FnRef` (a fn-pointer *value*, not just a call site) now
  respects `#[no_mangle]` — previously only call sites checked it.
- **BUG-232**: closure-environment leak triaged and fixed (surfaced by the
  BUG-201 double-free fix's own follow-up work).
- **BUG-233**: `#[bounded_stack]` was silently charging 0 bytes for
  `extern "C"` callees, undercounting real stack depth.
- Fixed a closure-capture double-free; added `wrapping_add`/`wrapping_sub`/
  `wrapping_mul` builtins.
- Fixed 753 instances of double-encoded mojibake across diagnostic text
  and source comments (garbled non-ASCII output from an earlier encoding
  bug in the diagnostics pipeline).
- `leak_sweep`'s LeakSanitizer check no longer flags `detach()`'s own
  inherently-flaky (by design — a genuinely detached task can still be
  running when the process exits) leak report as a real regression.

## Known issues (not fixed in this release)

- **Gap #5** (logged, not yet triaged into `src/`): the C backend emits a
  raw pointer instead of copying array contents when a struct literal's
  array-typed field is initialized from an existing local array/field
  variable (works correctly on the LLVM backend). Affects `--backend=c`
  only; DhruvaOS and other LLVM-only consumers are unaffected. See
  `docs/TODO_CURRENT.md` BUG-235 for the full writeup and repro.

## Upgrade notes

- No breaking changes. All new syntax/attributes are additive.
